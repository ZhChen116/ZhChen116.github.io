Privacy policy for gmail-mcp

Last updated: November 6, 2026

gmail-mcp is a personal, single-user tool run by ZH on ZH's own computer to read and manage ZH's own mailboxes.

Data accessed

With the user's consent, the tool uses the Google Gmail API scopes gmail.readonly, gmail.compose or gmail.modify, depending on the access level the user chooses for each mailbox. It reads message headers, bodies and attachments of the signed-in account, and it can create drafts, send mail, change labels or move mail to trash. It never permanently deletes mail.

How data is used

Every send, draft, label change or trash action is shown to the user as a preview and runs only after the user explicitly confirms it.

How data is stored

Mail is read on the user's own computer only to show it to that same user. OAuth tokens and any saved attachments stay on that computer. There is no server and no analytics.

Sharing

No Google user data is sold, shared with or transferred to any third party. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
